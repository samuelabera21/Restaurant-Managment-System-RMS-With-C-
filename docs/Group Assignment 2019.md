**Group size:** 5–6 students **Duration:** 2 months **Phases & Marks:**

- Web Application: **5 marks** 

- Group participation (individual contribution): **4 marks Total:** 15 marks 

Students work in phases. Each phase is graded even if later improvements are added. 

# **1. Project Process** 

## **Phase 1 Desktop Application (Weeks 1–3)** 

- Event-driven UI (buttons, forms, validation, navigation) 

- Local memory storage (no database required yet) 

- Basic business logic 

- Clean UI and structure 

### **Grading after Phase 1** 

## **Phase 2 API + Data Layer (Weeks 4–6)** 

- Create REST API (ASP.NET Web API) 

- Connect Desktop app to API 

- Add database (SQL Server/PostgreSQL) 

- Implement CRUD operations 

### **Grading after Phase 2** 

## **Phase 3 Web Application (Weeks 7–8)** 

- Web UI (ASP.NET MVC / Razor / minimal frontend) 

- Connect to same API 

- Authentication (basic) 

- Reports or dashboards 

- You can use AI for the web app. 

### **Final grading**
